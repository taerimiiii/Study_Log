Q1. 익명 클래스를 람다로 바꿀 수 없는 경우로 요약에 해당하는 것은?

A) 람다가 더 짧아 보일 때
B) 익명 클래스의 this/super 의미와 람da에서의 의미가 다를 때
C) Comparator를 구현할 때
D) Runnable을 한 번만 사용할 때

정답: B


Q2. 람다 스트림 디버깅과 테스팅에 대한 설명으로 옳은 것은?

A) 람다 표현식 자체를 반드시 public으로 노출해야 JUnit으로 테스트할 수 있다
B) peek은 스트림 파이프라인 각 연산 전후의 중간값을 확인하는 데 쓸 수 있다
C) 스트림에서 NPE가 나면 스택 트레이스에는 람다 코드 위치가 전혀 나타나지 않는다
D) 복잡한 람da는 테스트 불가능하므로 익명 클래스로 되돌려야 한다

정답: B
