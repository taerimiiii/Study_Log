# [5장] 스트림 활용

Q1. 칼로리 오름차순으로 정렬된 specialMenu에서 320칼로리 미만 요리만 골라 그 지점에서 반복을 중단하려 할 때, 요약에서 권장하는 연산과 그 이유로 맞는 것은?

A) filter — 모든 요소에 프레디케이트를 적용해야 정확하다
B) takeWhile — 정렬을 이용해 조건이 처음 거짓이 되면 더 이상 처리하지 않는다(쇼트서킷에 가깝다)
C) dropWhile — 320 미만인 요소만 남긴다
D) limit(320) — 상위 320개 요소만 선택한다

정답: B


Q2. anyMatch, allMatch, noneMatch 세 연산이 공통으로 활용한다고 요약에 나온 최적화 기법 이름을 적으시오.

정답: 쇼트서킷 (short-circuit)

해설: 조건을 만족하는 순간(또는 반례가 나온 순간) 나머지 요소를 처리하지 않고 결과를 반환할 수 있다.
