Q1. 람다 표현식을 사용할 수 있는 문맥(Context)이 되는 '함수형 인터페이스'에 대한 설명으로 가장 올바른 것은?

A. 두 개 이상의 추상 메서드가 정의되어 있어 다양한 동작을 수행할 수 있는 인터페이스
B. 디폴트 메서드(Default Method)와 정적 메서드만으로 구성된 인터페이스
C. 오직 하나의 추상 메서드만 지정하는 인터페이스
D. 아무런 메서드도 정의되지 않은 마커 인터페이스(Marker Interface)

정답: C


Q2. 람다 표현식 내부에서 외부의 변수를 참조하는 '람다 캡처링'에 대한 설명 중, 지역 변수(Local Variable)를 사용할 때의 제약과 그 이유가 옳은가? (O/X)

지역 변수는 반드시 static으로 선언되어야 한다. 메모리의 힙(Heap) 영역에 저장되어 람다가 언제든 참조해야 하기 때문이다.

정답: X
해설: 지역변수는 메모리의 스택(Stack) 영역에 저장된다.
