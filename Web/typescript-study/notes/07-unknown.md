# unknown 값 구분하기

- 코드: [src/07-unknown.ts](../src/07-unknown.ts)

## 실행 결과

| 입력 | 출력 | 분기 |
| --- | --- | --- |
| `1` | `현재 1주차예요.` | `typeof week === "number"` |
| `"1주차"` | `입력한 주차: 1주차` | `typeof week === "string"` |
| `null` | `주차를 확인할 수 없어요.` | 그 밖의 값 |
| `{ week: 1 }` | `주차를 확인할 수 없어요.` | 그 밖의 값 |

## 반환 타입 추론 결과

반환 타입을 직접 적지 않았는데 TypeScript는 **`string`** 으로 추론해요. 세 개의 `return`이 모두 문자열이기 때문이에요.

## 확인한 점

- `week`는 `unknown`이라서 `typeof` 확인 전에는 `week.toFixed()` 같은 메서드를 바로 쓸 수 없어요. 분기 안에서 `number`, `string`으로 좁혀진 뒤에만 사용할 수 있어요.
- `any`였다면 확인 없이도 컴파일이 통과해서, 잘못된 값이 들어와도 실행 중에야 문제를 알게 돼요.
